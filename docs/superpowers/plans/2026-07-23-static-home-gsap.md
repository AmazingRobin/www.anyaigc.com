# Static Homepage GSAP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the React-rendered homepage with static HTML driven by local GSAP and ScrollTrigger while matching the original layout, scroll scenes, and interactions.

**Architecture:** `index.html` remains the content document and the existing `data-motion` attributes form the controller contract. `assets/static/home.js` owns GSAP state, ScrollTrigger pinning, and native interaction events. `assets/static/home.css` supplies only static-entry and native-overlay styles; it does not recreate scroll sequences with CSS keyframes.

**Tech Stack:** HTML5, CSS, vanilla JavaScript, locally vendored GSAP 3 / ScrollTrigger, PowerShell, Playwright CLI.
